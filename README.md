# Econometrics with R Programming
In this repository, Authors wanted to present various econometric model estimations using R programming language. Several domain knowledges within include Economics, Financial Economics,
Banking & Finance. Most of the estimations would utilize time series data, but it does not mean that panel data would not be employed. Additionally, all estimations are intended for portfolios only, hence
cannot be used for formal research purpose. Please refer to all cited bibliography for further information of all models.
